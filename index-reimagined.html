Microclaw

Passed Microsoft AppSource certification

A production Microsoft 365 RAG agent that lives inside Teams. It works across email, calendar, tasks, files, notes, and channels from one conversation, running on Microsoft Graph with delegated OAuth. I built it solo, end to end. The engineering that matters is the ML around the agent loop: an orchestration harness, KNN tool selection at 95% recall, RAG semantic memory, a model router, and a 107-test eval harness benchmarked against another agent.

Agent orchestration loop

The hard, scarce part

An iterative plan/act/observe loop on Azure OpenAI function-calling that chains up to 35 tool calls per task. It escalates gpt-4o-mini to gpt-4o mid-task when an iteration emits more than 3 tool calls. Multi-layer failure recovery handles Graph 429/5xx with exponential backoff and 3 retries honoring Retry-After, detects loops at 8 repeats, and aborts cleanly at the 35-call cap.

KNN tool retrieval

95% recall over 84 tools

Two-stage selection: KNN over 1,045 synthetic training examples plus a keyword union, with a retry-against-all-84-tools fallback. k=7, 0.80 cosine threshold, text-embedding-3-small. Measured 95.0% recall vs 92.7% embedding-only, and ~6 of 84 tools selected per request instead of 18.

RAG semantic memory

Per-user persistent memory

Cosine-similarity retrieval over user-scoped memory entries. selectMemoriesForMessage(message, entries, topN) returns the top-N relevant memories per turn. History compression keeps entity references alive through structured tool-call summaries.

Smart model router

Mini default, escalate on complexity

gpt-4o-mini handles the default path and escalates to gpt-4o mid-conversation when tool-call complexity spikes. The mini path is about 24× cheaper per call than gpt-4o. Cost and latency are design variables, not afterthoughts.

Eval framework

107 tests, expected-facts scoring

An in-house suite of 107 hand-crafted tests under src/eval/ with expected-facts grading, accuracy and quality dimensions, and A/B comparison against a baseline agent. I iterated round over round to close the gap to the benchmark.

Multi-tenant · Marketplace

The deployment vehicle

Delegated Entra auth with tenant_id on 27 tables plus Postgres row-level security (FORCE policies, NOBYPASSRLS app role). Billing runs through the Commercial Marketplace Fulfillment API v2 and Metering Service with 8-tier bracket pricing.

Why the loop is the story. When Microsoft made Copilot agentic with Copilot Cowork, it "brought the technology that powers Claude Cowork into Microsoft 365 Copilot." The model is interchangeable. The orchestration harness, planning, acting across many tools, keeping state and memory, routing models, is the hard part, hard enough that Microsoft went outside for it. I built that harness on Microsoft 365 by myself.
