Multi-Agent Workflow Engine — built from scratch mtichikawa.github.io/workflow-engine

A Python engine that turns a plain-English request into a control-flow graph of single-purpose agents, validated before it runs and gated on human approval before anything acts. The agents are a shared library reused across workflows rather than duplicated, and a learning loop improves each one from corrected examples rather than a fine-tune, taking a deliberately crippled specialist to a perfect score on a held-out eval after six exemplars. Tested on real public data in 12 unrelated domains, with bidirectional MCP interop as an edge-only adapter.

Python  ·  agentic orchestration  ·  MCP (client + server)  ·  contracts + recipes  ·  static graph validation
