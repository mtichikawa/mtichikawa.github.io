Projects

Multi-Agent Workflow Engine mtichikawa.github.io/workflow-engine

A Python engine, built from scratch on the standard library, that turns a plain-English request into a graph of single-purpose agents. Every workflow is statically validated before it runs, and any step that acts outside the engine must sit behind a human approval gate. A learning loop infers a team's unwritten rules from their corrections, with no fine-tuning: on 150 blind-written messages, routing accuracy rose from 59 to 97 percent. On 320 blind-written patient messages, its triage step sent all 160 medical ones to a person, with no false alarms.

Python  ·  agentic orchestration  ·  MCP (client + server)  ·  static graph validation

Terminal-Bench 3 Task github.com/mtichikawa/klavis-tb3-submission

An original task for the Terminal-Bench 3 agent benchmark. Two exports of the same orders disagree because of four overlapping defects, and the agent has to recover the right values and work out how many separate causes there are. Claude Code on Claude Opus 5 and Codex on GPT-5.6 failed all six trials. The reference solution scores 1 and doing nothing scores 0, so a zero means the agent failed, not the grader. Every agent got the numbers right and then reported the wrong number of causes.
